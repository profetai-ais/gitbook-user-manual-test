# AI Studio roles and permissions description

## **Functional Role Types in AI Studio**

The system presets three functional role types:

* **AI Studio Administrator:** Can browse all function menus in the platform, and can grant other users advanced operation rights to the knowledge base and assistant functions.
* **AI Studio collaborators:** Can browse the knowledge base, capabilities, analysis, templates and Agent function menus in the platform, and establish file knowledge bases and Agents suitable for different fields and scenarios.
* **AI Studio users:** are general users in the enterprise and can browse the knowledge base, templates and Agent function menus in the platform.
