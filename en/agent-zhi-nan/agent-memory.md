# Agent Memory

## Introduction

Agent Memory is a function that allows Agents to "remember" and "continue to use" key information in subsequent interactions to improve conversation coherence and task processing efficiency. When users provide information such as preferences, background information, common settings, project context, or fixed formats during the interaction, the system can organize these contents into reusable memories, allowing the Agent to automatically refer to them in subsequent conversations, reducing repeated explanations and back-and-forth confirmations.

For example, users' commonly used titles, tone styles, output formats (columns/tables/paragraphs), frequently processed product or project names, process preferences, common decision-making principles, and specifications that need to be maintained consistently over a long period of time can all be retained as memories and applied at the appropriate time.

The entrance to the memory function is in the "Personalization" tab of the avatar in the upper right corner.

### memory

Memory is divided into "storage memory" and "reference memory".

<figure><img src="../.gitbook/assets/image (137).png" alt=""><figcaption></figcaption></figure>

* **Save Memory**: When enabled, allows the Agent to store memories.
* **Reference Memory**: When enabled, allows the Agent to reference memories in the memory bank when responding.

## manage memory

The entrance to managing memory is in the "Management" button. Memory management is divided into "Personal Memory" and "Agent Memory".

<figure><img src="../.gitbook/assets/image (138).png" alt=""><figcaption></figcaption></figure>

### personal memory

When the reference memory function is turned on, the memory stored here can be called by all Agents. Personal memory entries can store up to 50 memories.

> Note: When the storage limit is exceeded, the system will automatically delete the least frequently used memory entry.

<figure><img src="../.gitbook/assets/image (139).png" alt=""><figcaption></figcaption></figure>

### Agent memory

When the reference memory function is turned on, the Agent can call the memory in its own memory bank. Each Agent can store up to 50 memory entries.

> Note: When the storage limit is exceeded, the system will automatically delete the least frequently used memory entry.

1. Please make sure "Save Memory" is turned on before using the memory function.
2. Select the agent of the conversation in the conversation interface and enter the content you want to remember.
3. After the memory is successful, the Agent will prompt you to go to "Personalization → Memory Management" to view the memory.
