# Management Agent

## **Type of Agent**

<figure><img src="../.gitbook/assets/image (135).png" alt=""><figcaption></figcaption></figure>

* **Chat Agent**: Interact directly with internal or external large language models through basic question and answer.
* **Workflow**: Workflow can be arranged to handle complex application scenarios.

> Note: "Chat Agent" cannot search for internal company information to generate replies. If you want to use internal company knowledge, please use a "knowledge" type Agent.

## **Assign Agent Library Manager**

<figure><img src="../.gitbook/assets/image (136).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (137).png" alt=""><figcaption></figcaption></figure>

1. Click the "… (More)" button in the upper left corner of the screen
2. Select "Assign"
3. Click the "User Menu" in the pop-up window to select users, or enter text to filter
4. Click\*\*"Agent Library Role Menu" to select the role to be assigned to the user
5. Click the "Invite" button to complete permission assignment
6. Click the "Remove" button on the far right of the user list to delete the permissions granted to the user

> If you want to change the role assigned to a user, click "Agent library role name" in the user column to reselect it.

## Export/Import Agent (JSON)

The export/import function can be used to back up Agent settings, move settings between different environments, or quickly copy similar Agents to reduce duplicate configuration costs.

### Export Agent

<figure><img src="../.gitbook/assets/image (138).png" alt=""><figcaption></figcaption></figure>

1. Go to the Agent list, or enter the edit page of the target Agent.
2. Move the mouse over the Agent table to be exported.
3. Select the Export button and the system will download a proas file.

### Import Agent

<figure><img src="../.gitbook/assets/image (139).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

1. Click the "… (More)" button in the upper left corner of the screen
2. Select "Import File"
3. Click the field to select the file to import
4. Click "OK" to import the specified file
